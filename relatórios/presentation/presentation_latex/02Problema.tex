\section{O Problema}

\begin{frame}

É comum, principalmente em problemas de bioinformática, que haja muito mais variáveis do que amostras. Isso é ruim, dado que a condição $ p > n $, para \textit{p} variáveis e \textit{n} amostras, leva a
\begin{itemize}
    \item alto custo computacional \textrightarrow mais memória ocupada; dados irrelevantes são avaliados
    \item overfitting \textrightarrow o modelo pode aprender relações que só existem naquele conjunto de dados
\end{itemize}

\end{frame}
