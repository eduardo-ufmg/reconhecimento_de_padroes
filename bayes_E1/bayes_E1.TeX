\section{Analysis of Covariance Matrix Methods}
\label{sec:covariance_analysis}

This section evaluates three approaches for computing covariance matrices in a Gaussian Naive Bayes classifier: full covariance, naive (diagonal covariance), and complete-set covariance. Their effects on classification accuracy and likelihood space are discussed.

\subsection{Methodologies}
\begin{itemize}
  \item \textbf{Full Covariance}: Computes class-specific covariance matrices using all feature interactions. Captures pairwise correlations within each class.
  \item \textbf{Naive Covariance}: Assumes feature independence by using diagonal covariance matrices (variances only). Ignores inter-feature correlations.
  \item \textbf{Complete-Set Covariance}: Derives a single covariance matrix from the entire dataset (ignoring class labels) and applies it to both classes. Reflects global correlations rather than class-specific ones.
\end{itemize}

\subsection{Accuracy Results}
The mean cross-validation accuracies (10-fold) for each method are:
\begin{itemize}
  \item Reference (scikit-learn GaussianNB): \(0.93 \pm 0.03\)
  \item Full covariance: \(0.94 \pm 0.03\)
  \item Naive covariance: \(0.90 \pm 0.03\)
  \item Complete-set covariance: \(0.92 \pm 0.04\)
\end{itemize}

The full covariance model achieved the highest accuracy, likely due to its ability to model class-specific feature correlations. The naive approach underperformed, as expected from its independence assumption. The complete-set method showed intermediate performance, suggesting that global correlations partially approximate class-specific structures.

\subsection{Discussion}
The full covariance method outperformed others by leveraging class-specific correlations, aligning with the reference model's behavior. However, its computational complexity increases with feature dimensionality. The naive approach suffered from oversimplification but remained robust to correlated features. The complete-set method's intermediate accuracy suggests that global covariance partially compensates for class-specific correlations, but its divergent likelihood space implies suboptimal class separation. This contradiction warrants further investigation into dataset-specific correlation structures.
